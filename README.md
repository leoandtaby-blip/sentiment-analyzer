# Sentiment Analyzer with Claude API





\## Description

A Python application that analyzes sentiment from product reviews using the Claude API. This project demonstrates integration with Anthropic's Claude model for natural language processing tasks.



\## Features

\- Analyzes sentiment of product reviews (positive, negative, neutral)

\- Uses Claude API for intelligent text analysis

\- Manages product inventory with CSV storage

\- Includes test suite for validation

\- Environment configuration management
